# ⚡ Syntra Solutions — Prisma Portal

> **"Aqui a diferença se faz presente."**

O **Prisma Portal** é uma plataforma web corporativa multifuncional desenvolvida para centralizar a gestão de múltiplos setores (RH, Financeiro, T.I. e Administração) em uma interface moderna, intuitiva e responsiva.

---

## 🎯 Sobre o Projeto
Este é um projeto corporativo de demonstração (**Empresa Teste**) focado em demonstrar arquitetura limpa, navegação por papéis/permissões e um design com estética *dark mode / glassmorphism*.

---

## 🛠️ Tecnologias Utilizadas

- **Front-end:** HTML5, CSS3 (Glassmorphism & Neon Accents), JavaScript (ES6+)
- **Back-end & Banco de Dados:** Python, Flask, SQLite
- **Ferramentas:** Visual Studio Code, Git/GitHub, GitHub Pages

---

## 🚀 Funcionalidades Principais

- 🔐 **Painel Multi-nível:** Acessos específicos para Cliente, RH, Financeiro, T.I., Operador, Analista e Administrador.
- ⏱️ **Gestão de Ponto & RH:** Solicitação de ajustes, visualização de folha e administração de colaboradores.
- 💼 **Gestão Financeira:** Controle de pagamentos, pedidos e valores a receber.
- 📦 **Catálogo de Pedidos:** Acompanhamento e gerenciamento de orçamentos e produtos.
